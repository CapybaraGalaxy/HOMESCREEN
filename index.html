Copias de Seguridad
Sincronización con GitHub Gist

Guarda y combina tus datos con un Gist. Los Gists nuevos son privados; los existentes conservan su visibilidad. El token solo se almacena en este navegador y nunca se incluye en la copia.

Qué sincronizar

Favoritos y datos de uso se eligen por separado. Al fusionar, se unen las listas guardadas sin duplicados. Para el uso se conserva el contador mayor de cada app; nunca se suman contadores, así que resincronizar no lo duplica ni representa estadísticas globales acumuladas.

Todavía no hay sincronizaciones en este navegador. Ver Gist
